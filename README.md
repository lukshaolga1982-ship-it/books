# Заказ рабочих тетрадей

Веб-приложение для Браславской гимназии имени И. Н. Волчкова.

## Возможности

- классы 5–11 с буквами и отдельные учебные группы;
- индивидуальный набор пособий для каждого списка;
- отдельное количество заказчиков для каждой позиции;
- редактирование цены непосредственно в заказе;
- расчёт суммы на ученика, класс/группу и всю гимназию;
- поиск и фильтрация по предметам;
- печатная версия заказа;
- автоматическое сохранение данных в онлайн-базе.

Каталог содержит 338 позиций, перенесённых из прайс-листа от 7 августа 2026 года.

## Запуск проекта

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для рабочей онлайн-базы необходима привязка Cloudflare D1 `DB`, указанная в `.openai/hosting.json`.

## Основные файлы

- `index.html` — стартовый файл для GitHub Pages;
- `app/order-app.tsx` — интерфейс и расчёты;
- `app/catalog.ts` — каталог пособий;
- `app/api/state/route.ts` — сохранение данных;
- `app/globals.css` — оформление и мобильная адаптация;
- `db/schema.ts` и `drizzle/` — структура онлайн-базы.
